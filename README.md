# Behnam Typing Assistant (BTA)

> Smart Persian & English Typing Assistant for Windows

Made with ❤️ for Persian Typists

## Features

- Auto correction with Space
- Auto correction with Enter
- Double Shift quick fix
- FA/EN floating indicator
- Windows tray app
- Auto start with Windows
